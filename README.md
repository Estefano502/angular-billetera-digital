Billetera Digital - Caso 2 (Angular)

Instrucciones para ejecutar el proyecto BilleteraDigital con Angular:

Primero asegúrate de tener instalado en tu computadora:
* **Node.js** (Versión 20 o superior)
* **Angular CLI** (Versión 21)

Con los siguientes comandos se puede verificar las versiones que tenemos instaladas:
```bash
#Para Node.js
node -v
#Para Angular
ng version
```

* **INSTALACIÓN Y CONFIGURACIÓN**

1. Clona o descarga este repositorio en tu computadora.
2. Ubicate en la carpeta del proyecto
3. En la terminal, instala las dependencias con el comando npm install

* **EJECUTAR LA APLICACIÓN**

1. En la termina, ejecuta el comando ng serve
2. Abre tu navegador web e ingresa a la dirección: http://localhost:4200/
